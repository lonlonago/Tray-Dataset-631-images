# Tray Dataset 631 images

​

In the rapid development of intelligent manufacturing and smart logistics, the demand for high-precision target detection data with AI visual applications such as automated warehousing, unmanned forklifts, and intelligent sorting is increasingly urgent.

This dataset contains 631 high-definition JPG images, covering a variety of warehouses, factories, logistics parks and other real scenes. It has been labeled with 2156 target boxes of pallets, fully supporting both Pascal VOC and YOLO formats. It is an ideal data foundation for the training of various mainstream target detection models.

📦 Data set core highlights

Focus on industrial pallet recognition: The category of tags is single and clear - pallet (pallet), focusing on the detection task of standard wooden, plastic and metal pallets, suitable for core industrial scenes such as automated inventorying, stack analysis, forklift navigation.

High Density Annotation, Covering Diverse Shapes: Each image contains an average of 3.4 trays, covering different angles, lighting, occlusion, stacking states and ground projection conditions, realistically reflecting the visual challenges in complex industrial environments.

Double-format output, ready to use: Synchronous delivery.

✅ XMLFile （VOCformat ）

✅ TXTFile （YOLOformat ）

Seamlessly integrate with leading frameworks such as YOLOv5/v8, Faster R-CNN, and SSD without format conversion, allowing for rapid model training.

Image clarity, authentic: All images are in JPEG format, with clear resolution, without data augmentation, to preserve the original imaging features and facilitate users to customize enhancement strategies according to their actual needs.
